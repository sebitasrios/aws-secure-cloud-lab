
# AWS Secure Cloud Lab

Laboratorio práctico de ciberseguridad en AWS.

## Objetivo

Demostrar cómo proteger recursos en la nube mediante controles de identidad, almacenamiento, redes y auditoría.

## Tecnologías

- AWS Emulator
- Docker
- AWS CLI
- Python
- Git y GitHub

## Servicios del laboratorio

- IAM: usuarios, roles y políticas de acceso.
- S3: almacenamiento y protección de archivos.
- VPC: redes y subredes.
- EC2: instancias y grupos de seguridad.
- CloudTrail: auditoría de operaciones.

## Alcance

El proyecto utiliza AWS Emulator para realizar pruebas locales de servicios AWS.

Las simulaciones no sustituyen la validación de controles de seguridad en AWS real.
